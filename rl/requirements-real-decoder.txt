# Optional dependencies for Phase 2's REAL (non-mock) decoder layer
# (rl/qec_problem.py, rl/bp_decoder_adapter.py, tests/rl/test_bp_decoder_adapter.py).

# These are separate from the top-level requirements.txt on purpose:
# requirements.txt is Karan's Deltaflow validation-framework dependency
# list and is out of scope for this package to modify. Phase 1's mock

# are never installed.
#
# All four install with prebuilt wheels on Windows/macOS/Linux for
# common Python versions - no Rust/C++ toolchain required.

#   pip install -r rl/requirements-real-decoder.txt
